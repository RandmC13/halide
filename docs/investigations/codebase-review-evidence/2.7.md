### 2.7-4: Dependencies are unbounded (no version pins or ranges)
- Severity: S5 (inconsistency, minor)
- Where: pyproject.toml:9-20
- Evidence: All runtime dependencies list no `>=`, `<=`, `~=`, or `==`:
  - numpy, tifffile, imagecodecs, colour-science, scipy, PySide6, pillow, psutil, shtab
  - Extras cuda12 and cuda13 do specify `>=14` (reasonable, but inconsistent with main deps)
- Implication: Installs will always pull latest compatible, which aids security updates but risks reproducibility if a future release has a breaking change in a minor version
- Requirement: None explicitly stated; practice varies (some projects pin everything, others trust semver)
- Suggestion: Consider adding loose floors (e.g., `numpy>=1.20`) for major dependencies if reproducibility matters, but not required for correctness
- Confidence: likely (read, not a correctness issue)
